16 TYPE GUIDE

ゲーマーMBTI 16タイプ別ガイド

診断結果の称号ごとに、強み、克服ポイント、相性、向きやすいロールを詳しく読めます。

鉄壁の記録官型ISTJ / 勝ち筋を崩さない、安定感のある実務派ゲーマー。 誓約の守護騎士型ISFJ / 気づいたらチームを助けている、安心感の守護役。 静かな預言者型INFJ / 勝ち筋と空気の両方を見て、チームを静かに整えるタイプ。 冷静沈着の軍師型INTJ / 試合の先を見て、勝つための構造を組み立てるタイプ。 無言の剣豪型ISTP / 説明よりプレイで見せる、現場対応のソロエース。 自由なる吟遊詩人型ISFP / 気持ちよく動ける時に、独自のセンスが爆発するタイプ。 夢見る巡礼者型INFP / ゲームの物語と仲間の気持ちを大事にする、共感型プレイヤー。 孤高の研究者型INTP / メタ、仕様、強行動を理詰めで読み解く分析ゲーマー。 電撃アサルト型ESTP / 前線で流れを奪う、脳汁系アタッカー。 祝祭の先陣役型ESFP / 勝っても負けても場を明るくする、通話映えタイプ。 ひらめき冒険家型ENFP / アイデアと勢いで、遊び方そのものを楽しくするタイプ。 メタ破壊の革命家型ENTP / 常識の穴を見つけて、相手の想定をずらすタイプ。 規律の実戦指揮官型ESTJ / 目的、役割、次の行動をはっきりさせる勝率管理タイプ。 陽だまりの宮廷官型ESFJ / みんなが遊びやすい場を作る、コミュニティ型サポーター。 鼓舞する旗手型ENFJ / 勝ち筋とテンションを同時に作る、熱いチームリーダー。 覇道コマンダー型ENTJ / 勝つための判断を恐れない、司令塔タイプ。
